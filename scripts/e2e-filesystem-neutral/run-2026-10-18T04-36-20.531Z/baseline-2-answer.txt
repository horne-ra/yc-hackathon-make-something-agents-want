This project is **Commander.js** (`commander` v13.1.0). It's a Node.js library for building command-line interfaces, written in CommonJS with an ESM wrapper and hand-written TypeScript typings. It requires Node 18 or later.

## Source code
- **`index.js`** is the CommonJS entry point. It exports the public API.
- **`esm.mjs`** is the ESM entry point. It re-exports the same API as named exports.
- **`lib/`** holds the implementation, split into six files:
  - `command.js`: the `Command` class, which handles parsing, subcommands, hooks, and executable subcommands.
  - `option.js`: the `Option` class and related helpers.
  - `argument.js`: the `Argument` class.
  - `help.js`: the `Help` class, which formats help output.
  - `error.js`: `CommanderError` and `InvalidArgumentError`.
  - `suggestSimilar.js`: the "did you mean…?" suggestions.
- **`typings/`** has the TypeScript types: `index.d.ts` for CJS, `esm.d.mts` for ESM, and `index.test-d.ts` for type tests run with `tsd`.

## Tests (`tests/`)
- Tests use **Jest**. There is roughly one file per feature, named like `command.*.test.js`, `option(s).*.test.js`, `argument.*.test.js` and `help.*.test.js`.
- Other tests include `program.test.js`, `deprecated.test.js` and `ts-imports.test.ts`.
- `esm-imports-test.mjs` is a standalone ESM check, run with `npm run test-esm`.
- `fixtures/` and `fixtures-extensions/` hold small stub executables, such as `pm-install` and `pm-cache.js`. The tests for git-style executable subcommands use them.

## Documentation and examples
- **`Readme.md`** is the main documentation. `Readme_zh-CN.md` is the Chinese version.
- **`docs/`** has deeper guides on help, options, parsing and hooks, terminology and deprecated features. `docs/zh-CN/` has Chinese translations.
- **`examples/`** has about 50 runnable samples. Some cover options (`options-*.js`), some cover help customization (`help-*.mjs`, `color-help.mjs`), and some cover subcommands (`pm`, `nestedCommands.js`, `deploy`).
- Project meta files include `CHANGELOG.md`, `CONTRIBUTING.md`, `SECURITY.md` and `LICENSE` (MIT).

## Tooling and config
- **Scripts in `package.json`:**
  - `npm test` runs Jest and the TypeScript checks.
  - `npm run check` runs the type, lint and format checks.
  - `npm run fix` auto-fixes lint and formatting problems.
  - `npm run test-all` runs everything.
- **Linting and formatting:** ESLint (`eslint.config.js`) and Prettier (`.prettierrc.js`, `.prettierignore`), plus `.editorconfig`.
- **Type checking:** `tsconfig.json`, `tsconfig.js.json` (type-checks the JS) and `tsconfig.ts.json` (type-checks TS usage).
- **Test runner:** `jest.config.js`.
- **CI:** `.github/workflows/` has `tests.yml` and `codeql-analysis.yml`. The `.github/` folder also holds the Dependabot config, the PR template and `FUNDING.yml`.
- **Published files:** only `index.js`, `lib/*.js`, `esm.mjs`, the typings and `package-support.json` go into the npm package.
