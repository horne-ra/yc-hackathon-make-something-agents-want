This project is **Commander.js** (`commander` v13.1.0). It's a library for building Node.js command-line programs: it parses options, arguments and subcommands, and generates help output. It's published as CommonJS with an ESM wrapper and TypeScript typings, and needs Node 18 or later.

## Layout

```
project/
├── index.js            # Package entry point (CommonJS)
├── esm.mjs             # ESM entry point
├── lib/                # Library source
│   ├── command.js          # Command class: parsing, subcommands, hooks, actions
│   ├── option.js           # Option class
│   ├── argument.js         # Argument class
│   ├── help.js             # Help class: help text formatting and styling
│   ├── error.js            # CommanderError, InvalidArgumentError
│   └── suggestSimilar.js   # "Did you mean ...?" suggestions
├── typings/            # TypeScript definitions
│   ├── index.d.ts          # Types for the CommonJS entry
│   ├── esm.d.mts           # Types for the ESM entry
│   └── index.test-d.ts     # Type tests (run with tsd)
├── tests/              # Jest test suite, about 130 files
│   ├── fixtures/           # Fake executable subcommands (pm-*, etc.)
│   ├── fixtures-extensions/  # Fixtures for .cjs/.mjs/.ts subcommand lookup
│   └── *.test.js           # Named by feature, e.g. command.*, option(s).*, help.*, argument.*
├── examples/           # About 45 runnable sample CLIs (options, help, nested commands, hooks, etc.)
├── docs/               # In-depth guides
│   ├── help-in-depth.md, options-in-depth.md, parsing-and-hooks.md
│   ├── terminology.md, deprecated.md
│   └── zh-CN/              # Chinese translations
├── .github/            # CI workflows (tests, CodeQL), Dependabot, PR template, funding
└── (config files)
```

## Architecture

`index.js` is a small facade. It creates a default `program` (a `Command`) and exports these:
- Factory helpers: `createCommand`, `createOption` and `createArgument`.
- Classes: `Command`, `Option`, `Argument` and `Help`.
- Error types: `CommanderError` and `InvalidArgumentError`. `InvalidOptionArgumentError` is a deprecated alias for `InvalidArgumentError`.

All the logic is in the six files under `lib/`, and `command.js` is the core of the library.

## Tooling and config

- **Testing:** Jest, configured in `jest.config.js`, plus `ts-jest` for the TypeScript tests. `tsd` checks the type definitions.
- **Linting and formatting:** ESLint 9 (`eslint.config.js`, with typescript-eslint) and Prettier (`.prettierrc.js`).
- **TypeScript:** `tsconfig.json`, `tsconfig.js.json` (type-checks the JS) and `tsconfig.ts.json` (checks the TS usage).
- **npm scripts:**
  - `npm test` runs Jest and the TS type checks.
  - `npm run test-esm` checks the ESM imports.
  - `npm run check` runs the type, lint and format checks.
  - `npm run test-all` runs everything.
  - `npm run fix` auto-fixes lint and formatting.
- **Published files:** only `index.js`, `lib/*.js`, `esm.mjs`, the typings and `package-support.json`.
- **Project docs:** `Readme.md` (with a `zh-CN` version), `CHANGELOG.md`, `CONTRIBUTING.md`, `SECURITY.md` and `LICENSE` (MIT).
