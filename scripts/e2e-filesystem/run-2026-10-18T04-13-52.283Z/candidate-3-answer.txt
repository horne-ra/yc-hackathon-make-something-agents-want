# Project overview: Commander.js (v13.1.0)

This is **Commander**, the Node.js library for building command-line interfaces. It's a plain CommonJS package with no runtime dependencies. It needs Node 18 or later and is MIT licensed. It ships hand-written TypeScript typings instead of being written in TypeScript.

## Top-level layout

| Path | Purpose |
|---|---|
| `index.js` | CommonJS entry point (`main`). |
| `esm.mjs` | ES module entry point, exposed through the `exports` map. |
| `lib/` | The implementation (see below). |
| `typings/` | `index.d.ts` and `esm.d.mts` are the shipped types. `index.test-d.ts` holds type tests run with `tsd`. |
| `tests/` | Jest test suite plus fixtures. |
| `examples/` | About 50 runnable sample CLIs. |
| `docs/` | In-depth guides, with some Chinese translations in `docs/zh-CN/`. |
| `.github/` | CI workflows (`tests.yml`, `codeql-analysis.yml`), Dependabot config, and the PR template and funding file. |

## Source (`lib/`)
- `command.js` is the core `Command` class. It handles parsing, subcommands, actions, hooks and executable subcommands.
- `option.js` defines the `Option` class.
- `argument.js` defines the `Argument` class.
- `help.js` generates and formats help output.
- `error.js` holds the error types, such as `CommanderError` and `InvalidArgumentError`.
- `suggestSimilar.js` provides the "did you mean…" suggestions.

The `files` field in `package.json` shows that only `index.js`, `lib/*.js`, `esm.mjs`, the two typings files and `package-support.json` are published.

## Tests (`tests/`)
Tests are mostly one file per feature, named by area:
- `command.*.test.js` covers commands (action, alias, hooks, exitOverride, executableSubcommand and so on).
- `options.*.test.js` and `option.*.test.js` cover options (env, defaults, variadic, choices, conflicts, implies and so on).
- `argument.*.test.js` and `args.*.test.js` cover arguments.
- `help.*.test.js` covers help formatting.
- Miscellaneous tests include `program.test.js`, `deprecated.test.js`, `useColor.test.js`, `ts-imports.test.ts` and `esm-imports-test.mjs`.
- `fixtures/` and `fixtures-extensions/` hold fake `pm-*` executable subcommands used to test the git-style subcommand feature. The `.cjs`, `.mjs` and `.ts` variants cover different file extensions.

## Tooling and scripts
- **Testing:** Jest (`jest.config.js`) with ts-jest. `npm test` runs Jest and then the TypeScript checks.
- **Type checks:** `tsd` and `tsc`, using `tsconfig.js.json` (checks the JS) and `tsconfig.ts.json` (checks the TS usage).
- **Lint and format:** ESLint 9 (`eslint.config.js`, with typescript-eslint and the Jest plugin) and Prettier (`.prettierrc.js`).
- **Useful scripts:**
  - `npm run check` runs types, lint and format checks.
  - `npm run fix` auto-fixes lint and formatting.
  - `npm run test-esm` checks the ESM imports.
  - `npm run test-all` runs everything.

## Documentation
The root has `Readme.md` (plus a Chinese `Readme_zh-CN.md`), `CHANGELOG.md`, `CONTRIBUTING.md` and `SECURITY.md`. The guides in `docs/` cover help, options, parsing and hooks, terminology and deprecated features.

I only read `package.json` and the directory listing. I haven't opened the source files, so the descriptions of `lib/` come from file names and Commander's public API.
