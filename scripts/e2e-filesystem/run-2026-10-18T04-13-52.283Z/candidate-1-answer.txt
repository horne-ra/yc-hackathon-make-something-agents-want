# Project overview: Commander.js

This is **Commander.js** v13.1.0, the Node.js library for building command-line interfaces. It's published as `commander`, uses the MIT license, and requires Node 18 or later. The package is CommonJS with an ESM wrapper.

## Layout

```
commander/
├── index.js            # CJS entry point (package "main")
├── esm.mjs             # ESM entry point
├── lib/                # Library source
│   ├── command.js      # Command class: parsing, subcommands, hooks, actions
│   ├── option.js       # Option class
│   ├── argument.js     # Argument class
│   ├── help.js         # Help formatting and output
│   ├── error.js        # Error types (e.g. CommanderError)
│   └── suggestSimilar.js  # "Did you mean ...?" suggestions
├── typings/            # TypeScript types
│   ├── index.d.ts      # Types for CJS
│   ├── esm.d.mts       # Types for ESM
│   └── index.test-d.ts # Type tests (run with tsd)
├── tests/              # Jest test suite
│   ├── fixtures/, fixtures-extensions/  # Fake executable subcommands for tests
│   └── ...
├── examples/           # About 50 small runnable sample CLIs
├── docs/               # Long-form docs
│   └── zh-CN/          # Chinese translations
└── Readme.md, Readme_zh-CN.md, CHANGELOG.md, CONTRIBUTING.md, SECURITY.md, LICENSE
```

## Source (`lib/`, `index.js`, `esm.mjs`)
- The code is split by concept: `Command`, `Option`, `Argument`, `Help`, and errors. `suggestSimilar.js` is a helper for typo suggestions.
- `index.js` and `esm.mjs` are the two entry points. `package.json`'s `exports` field routes `require` and `import` to them, each with matching type definitions.
- Only `index.js`, `lib/*.js`, `esm.mjs`, the two typings files, and `package-support.json` are published (the `files` field).

## Tests (`tests/`)
- Jest runs the tests, configured in `jest.config.js`.
- File names follow the feature they cover:
  - `command.*.test.js` covers `Command` behavior such as actions, aliases, hooks, help, and executable subcommands.
  - `options.*.test.js` and `option.*.test.js` cover option handling such as defaults, env vars, choices, conflicts, and variadic options.
  - `argument.*.test.js` and `args.*.test.js` cover arguments.
  - `help.*.test.js` covers help text generation and styling.
- There are also ESM import tests (`esm-imports-test.mjs`), a TypeScript import test (`ts-imports.test.ts`), and tests for deprecated features.
- The `fixtures*` folders hold fake `pm-*` executables, which model git-style subcommands.

## Examples and docs
- `examples/` has one small script per feature, such as `options-required.js`, `nestedCommands.js`, `hook.js`, and `custom-help-text.js`. Files without an extension, such as `pizza`, `deploy`, and `pm`, are executable-subcommand demos.
- `docs/` has in-depth guides on help, options, parsing and hooks, terminology, and deprecated features. Some are translated into Chinese.

## Tooling and config
- **Scripts** (from `package.json`):
  - `npm test` runs Jest, then the TypeScript type checks.
  - `npm run check` runs type checking, ESLint, and Prettier.
  - `npm run fix` auto-fixes lint and formatting issues.
  - `npm run test-esm` runs the ESM import test.
- **Linting and formatting:** `eslint.config.js`, `.prettierrc.js`, `.prettierignore`, and `.editorconfig`.
- **TypeScript:** `tsconfig.json`, `tsconfig.js.json` (type-checks the JS), and `tsconfig.ts.json` (type-checks the TS tests and typings).
- **CI:** `.github/workflows/` has `tests.yml` and `codeql-analysis.yml`. Dependabot is also configured.
- **Dev dependencies:** Jest and ts-jest, ESLint and typescript-eslint, Prettier, tsd, and TypeScript. The library itself has no runtime dependencies.
