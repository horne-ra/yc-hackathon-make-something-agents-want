# Project overview: Commander.js

This is **commander** v13.1.0, the Node.js library for building command-line interfaces. It's a plain CommonJS package with hand-written TypeScript typings. It requires Node 18 or later and is MIT licensed.

## Top-level layout

| Path | Purpose |
|---|---|
| `index.js` | Main entry point, which is the `main` and `require` target. |
| `esm.mjs` | ES module entry point, used for `import`. |
| `lib/` | Core implementation (see below). |
| `typings/` | TypeScript declarations: `index.d.ts` for CJS, `esm.d.mts` for ESM, and `index.test-d.ts` for type tests run with `tsd`. |
| `tests/` | Jest test suite plus fixtures. |
| `examples/` | About 45 small runnable example CLIs. |
| `docs/` | In-depth guides, plus Chinese translations in `docs/zh-CN/`. |
| `.github/` | CI workflows (`tests.yml`, `codeql-analysis.yml`), Dependabot config, and PR template. |

## Core source (`lib/`)

The library is small, with one file per concept:
- `command.js` is the main `Command` class. It handles parsing, subcommands, actions, hooks, and executable subcommands.
- `option.js` defines the `Option` class and related helpers.
- `argument.js` defines the `Argument` class.
- `help.js` defines the `Help` class, which formats and styles help output.
- `error.js` defines `CommanderError` and `InvalidArgumentError`.
- `suggestSimilar.js` provides the "did you mean…?" suggestions.

## Public API and packaging
`package.json` uses conditional `exports`. `require` loads `index.js` with `typings/index.d.ts`. `import` loads `esm.mjs` with `typings/esm.d.mts`. Only `index.js`, `lib/*.js`, `esm.mjs`, the typings, and `package-support.json` are published.

## Tests (`tests/`)
Tests are named by feature area:
- `command.*.test.js` covers commands: actions, aliases, hooks, help, executable subcommands, parsing, and so on.
- `options.*.test.js` and `option.*.test.js` cover options: booleans, defaults, env vars, variadic, choices, conflicts, implies, and so on.
- `argument.*.test.js` and `args.*.test.js` cover arguments.
- `help.*.test.js` covers help formatting, wrapping, sorting, and styling.
- Other tests include `esm-imports-test.mjs`, `ts-imports.test.ts`, `deprecated.test.js`, and `useColor.test.js`.
- `fixtures/` and `fixtures-extensions/` hold fake executable subcommands (the `pm-*` files) used to test subcommand lookup and process handling.

## Tooling
- **Testing:** Jest with ts-jest (`jest.config.js`), plus `tsd` for type tests.
- **Type checking:** `tsc` with separate configs for JS (`tsconfig.js.json`) and TS (`tsconfig.ts.json`).
- **Linting and formatting:** ESLint 9 (`eslint.config.js`) and Prettier (`.prettierrc.js`).
- **Scripts:**
  - `npm test` runs Jest and the TS type checks.
  - `npm run test-all` adds the ESM import test and the full lint, type and format check.
  - `npm run fix` auto-fixes lint and formatting issues.
